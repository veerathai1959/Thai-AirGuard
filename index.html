รอบสแกนและเงื่อนไขแจ้งเตือน

ข้อจำกัดบน iPhone / iPad: การแจ้งเตือนผ่านเบราว์เซอร์ (Notification) ทำงานได้เฉพาะเมื่อเพิ่มเว็บลงหน้าจอโฮมเป็น PWA และเปิดแอปค้างไว้เท่านั้น หากปิดแอปจะไม่แจ้งเตือนพื้นหลัง

อีเมล / SMS / LINE ต้องมีเซิร์ฟเวอร์ส่งแทน (เว็บเปล่าส่งเองไม่ได้) จึงยังไม่เปิดให้ใช้ในหน้านี้

แหล่งข้อมูลจุดความร้อนและ Proxy / Worker

ความปลอดภัยของ MAP_KEY: คีย์ที่ใส่ในเครื่องถูกเก็บใน localStorage ของเบราว์เซอร์นี้และแนบไปกับ URL ของ FIRMS แนะนำให้ใช้ Worker เก็บคีย์ฝั่งเซิร์ฟเวอร์เป็นหลัก และไม่แชร์เครื่อง/ไฟล์ที่มีคีย์ให้ผู้อื่น

ใช้ NOAA-20 และ NOAA-21 เป็นหลัก (SNPP เป็นแหล่งเสริม) ขอข้อมูล 2 วันแล้วกรองอายุไม่เกิน 24 ชม. เฉพาะประเทศไทยและชายแดนประเทศเพื่อนบ้านโดยรอบ

PWA โหลดไฟล์และคู่มือติดตั้ง

เพื่อให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ ให้วาง index.html, manifest.json และ sw.js ไว้โฟลเดอร์เดียวกันบนโฮสต์ HTTPS (Service Worker ต้องเป็นไฟล์จริงบนโดเมนเดียวกัน)

1. ติดตั้งบนเซิร์ฟเวอร์ / โฮสต์ (HTTPS)

  1. อัปโหลดทั้ง 3 ไฟล์ขึ้นเซิร์ฟเวอร์ที่รองรับ HTTPS เช่น GitHub Pages, Cloudflare Pages หรือเว็บเซิร์ฟเวอร์ทั่วไป
  2. เปิดผ่าน https:// เพื่อให้ Service Worker และ GPS ทำงานสมบูรณ์
  3. หากสถานี Air4Thai ติดบล็อก CORS หรือต้องการซ่อน FIRMS MAP_KEY ให้ตั้งค่า Proxy / Worker ด้านบน

2. ติดตั้งบนมือถือ (Android / iPhone)

  1. Android (Chrome): แตะเมนู ⋮ → ติดตั้งแอป หรือ เพิ่มไปยังหน้าจอหลัก
  2. iPhone (Safari): แตะ แชร์ → เพิ่มไปยังหน้าจอโฮม

3. ติดตั้งบนแท็บเล็ต / iPad

  1. iPad (Safari): แตะ แชร์ → เพิ่มไปยังหน้าจอโฮม
  2. Android Tablet (Chrome): เมนู ⋮ → ติดตั้งแอป

เกี่ยวกับข้อมูลและโหมดออฟไลน์

PM2.5: สถานีตรวจวัดกรมควบคุมมลพิษ (Air4Thai) ใช้เฉพาะสถานีที่สดภายใน 3 ชม. และอยู่ห่างไม่เกิน 50 กม. · พยากรณ์/ย้อนหลัง: Open-Meteo (CAMS) · จุดความร้อน: NASA FIRMS (VIIRS) NOAA-20/NOAA-21 เป็นหลัก ดึงย้อนหลัง 2 วันและกรองอายุ ≤ 24 ชม. เฉพาะไทยและชายแดนใกล้เคียง

โหมดออฟไลน์: เมื่อไม่มีอินเทอร์เน็ต แผนที่ (ไทล์แผนที่/ภาพดาวเทียม) การค้นหาสถานที่ และข้อมูลสดจากบริการภายนอกอาจใช้ไม่ได้หรือแสดงได้เฉพาะข้อมูลแคชที่มีอยู่เดิม ระบบจะไม่ใช้ข้อมูลเก่า/แคชยิงแจ้งเตือนสด

ข้อจำกัด: ข้อมูลจุดความร้อนจากดาวเทียมมีดีเลย์ราว 3 ชม. และดาวเทียมผ่านเพียงบางช่วงของวัน การ ไม่พบจุดความร้อนไม่ได้หมายความว่าไม่มีไฟ แต่ละจุดคือพิกเซล VIIRS ขนาดราว 375 ม. ไม่ใช่ขนาดพื้นที่เผาไหม้จริง แอปนี้ไม่ใช่ข้อมูลทางการ โปรดใช้ประกอบกับประกาศของหน่วยงานรัฐ และโทร 1784 / 191 เมื่อพบเหตุไฟไหม้
